پروژه MaxFinder

یک برنامه خط فرمان جاوا که بزرگ‌ترین عدد را از لیستی از اعداد پیدا می‌کند.

ساخت و اجرا (با Maven):

1) بیلد و تولید فایل اجرایی:
   mvn package

2) اجرای برنامه با آرگومان‌ها:
   java -jar target/maxfinder-1.0-SNAPSHOT.jar 3 7 2 5
   خروجی: 7

3) یا از طریق stdin:
   echo "3 7 2 5" | java -jar target/maxfinder-1.0-SNAPSHOT.jar

رفتار در مواجهه با خطاها:
- در صورت دریافت ورودی خالی، برنامه پیام خطا چاپ می‌کند و با کد خروج 1 خارج می‌شود.
- در صورت وجود توکن غیرقابل تبدیل به عدد، برنامه پیام خطا چاپ می‌کند و با کد خروج 2 خارج می‌شود.

تست‌ها:
   mvn test

نکات:
- اعداد به صورت double پردازش می‌شوند. برای نیاز به دقت یا عدد صحیح خیلی بزرگ، می‌توان از BigDecimal/BigInteger استفاده کرد.
